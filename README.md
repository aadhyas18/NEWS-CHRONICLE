# NEWS-CHRONICLE
A NEWS chronicle home page designed using html,css and java script.

A responsive news portal website built using **HTML, CSS, and JavaScript**. It organizes news articles into different categories and provides an easy way to explore headlines, trending stories, and the latest news.

## 📌 Project Overview

Daily News is a front-end web development project designed to present news content in a clean, organized, and user-friendly interface. The website features a featured headline section, category-based news filtering, a search bar, and a trending stories sidebar.

## ✨ Features

- **Featured Headlines:** Highlights the main news story on the homepage.
- **Latest News:** Displays news articles in organized cards.
- **News Categories:** Browse World, Technology, Sports, Business, and Entertainment news.
- **Breaking News Ticker:** Displays scrolling headline text.
- **Search Functionality:** Search articles by title, description, or category.
- **Trending Stories:** Displays selected popular stories in a numbered list.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Newsletter Form:** Demonstrates a basic newsletter signup interface.
- **Interactive Elements:** Includes hover effects, category filters, and a mobile navigation menu.

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage and its content.
- **CSS3** – Provides styling, layouts, animations, and responsive design.
- **JavaScript** – Handles article rendering, search, category filtering, and interactive features.
- **Unsplash Images** – Provides sample images for news articles.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in Visual Studio Code for a convenient development experience.

## 📖 How It Works

1. HTML creates the header, navigation bar, featured headline, news section, trending sidebar, and footer.
2. CSS styles the website and adjusts its layout for different screen sizes.
3. JavaScript stores sample news data in an array and dynamically creates article cards.
4. Category filters display articles belonging to the selected category.
5. The search function finds matching articles based on the entered keyword.
6. Trending stories are selected using a property in the article data.

## ⚠️ Current Limitations

- The website currently uses sample news articles and manually selected trending stories.
- Live news updates are not implemented.
- The newsletter form is a front-end demonstration and does not store email addresses.
- The Read More action currently displays a sample article message rather than a full article page.
- An internet connection is needed to load externally hosted Unsplash images.
